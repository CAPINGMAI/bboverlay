================================================================
        bboverlay —— 黑匣子 + 眼镜视频 叠加工具 使用说明
================================================================

【一、先放好两个第三方程序】
程序需要 ffmpeg 和 blackbox_decode，本仓库不附带（见 tools/README.md）：
  tools\ffmpeg.exe
  tools\blackbox_decode.exe
或设置环境变量 FFMPEG / BLACKBOX_DECODE 指向它们。

Windows 上可以自动下：
  powershell -ExecutionPolicy Bypass -File tools\download-tools.ps1

【姿态与摇杆校准 v1.5】
· 姿态来源：默认「积分（稳）」；觉得姿态歪/转圈可换「重力（新）」试试
· 机头偏置：如果模型看着是「侧着、转 90°」，把这里改成 90°/180°/270°（补偿飞控板装转）
· 摇杆方向：「跟随杆位」=推杆向前点在屏幕上方（FPV 习惯）；「跟随机头」=推杆向前是抬头
· 摇杆自动校准：按摇杆指令与陀螺的相关性自动判断通道要不要反向

【分得清正飞/倒飞】（高级效果 → 勾「3D 姿态画人工地平线」）
· 飞机外面套一个「人工地平线」圆盘：上半蓝＝天空、下半棕＝地面，跟着姿态转，倒过来一眼就看出来
· 飞机上方有绿色 UPRIGHT / 红色 INVERTED 徽标
· 机体顶面比底面亮很多（倒飞时看到的是深色底）

【竖屏原生排版 v1.4】
高级效果里画幅选 9:16 + 勾「竖屏排版」，程序会按 1080x1920 重新排版：
地图左上、3D 姿态居中、两根摇杆并排放下方、数值面板右侧、柱状图左下，字号也放大。
命令行：--size 9:16 --portrait（--portrait-mode native|band，band 是旧的整块缩小方式）

【版本号 / 崩溃日志 / 面板可拖】
· 标题栏会显示版本号（v1.3），生成日志里也有一行
· 万一崩了会自动写 crash.log（在程序文件夹），把那个文件发出来就能定位
· 「元素位置」里多了一个紫色框「面板/柱状图/文字」：勾了数值面板/柱状图/水印后
  可以直接拖动这三样东西的位置（整体一起动）

【GPS 遮盖默认位置】
黑块默认改成了「顶部整条」(0,0,1920,46)：眼镜画面里经纬度就在最上面那一行，
勾上「GPS 坐标遮盖 1」并把透明度拉到 1.0 就能整条盖住。
如果 OSD 布局不同，进「元素位置」拖一下黑块或直接改坐标。

【竖屏 9:16 排版】
高级效果里选画幅 9:16，勾「竖屏排版」：视频铺满整块竖屏，HUD 等比缩小压在底部
（可选 底部/居中/顶部），摇杆不会被裁掉。命令行：--size 9:16 --portrait --hud-pos bottom

【高级效果】（主界面「画面」卡片里点「高级效果」）
· 数值面板：油门/电压/电流/速度/高度/卫星，位置字号可调
· 条形图：油门、电压竖条
· 自定义文字：机主名/日期，位置+字号+锚点可调
· 摇杆轨迹：长度、粗细、颜色
· 小地图附加：比例尺、速度矢量、航点圆点、解锁/上锁标记
· 画面观感：暗角、四角圆角
· 画幅：16:9 / 1:1 / 4:5 / 9:16，补黑边 或 裁切填满
· 3D 模型：填 .obj 路径（assets/示例模型.obj 是个示例），留空用内置方块飞机
提示：竖屏 9:16 选「裁切填满」时画面最满，但两侧 HUD 会被裁；想 HUD 完整就选「补黑边」。

【小地图 / 黑块的形状和透明度】
「画面」里：小地图可以选 矩形 / 圆角矩形 / 椭圆，并调透明度；
GPS 坐标遮盖块同样可选形状和透明度（透明度 1=全黑不挡画面，0.6 之类是半透明压暗）。
命令行对应 --map-shape / --map-alpha / --mask-shape / --mask-alpha。

【摇杆样式】
「画面」里可以选：经典圆盘 / 圆角方框（示例那种半透明方框）/ 极简圆 / 极简方框，
还能调透明度、框线颜色、点颜色，勾「显示 us 数值」会在每个摇杆上下显示 1505 us 这种数值。
现在的成品是真正按透明度叠到视频上的（半透明就是半透明），绿幕 overlay 仍然是绿底，给剪映抠图用。

【提示】配置程序里下载 ffmpeg 要 100 MB 左右，网络慢时会等几分钟；
窗口不会卡死，标题栏不用管，下面会显示「已等 N 秒 / 已下载 N MB」，等它跑完就行。

【两个启动器都可以用】
· 启动黑匣子叠加工具.exe  —— 双击即可（若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」）
· 启动黑匣子叠加工具.vbs  —— 老办法；学校/公司的电脑如果禁用了脚本，就用上面的 exe
两个作用完全一样，任选一个。被杀毒软件拦了就把整个文件夹加白名单。

【出问题了先做体检】
双击「环境体检.vbs」：会逐项检查系统/权限/程序文件/Python 及依赖/ffmpeg/解码器/网络/启动器/杀软，
有问题的地方标 [!!]，报告同时存成「体检报告.txt」，可以发给别人帮忙看。

【双击启动器没反应怎么办】
1. 先双击「新电脑配置程序.vbs」跑一遍，等它显示「配置完成」
2. 还不行就把整个压缩包重新解压覆盖（不要只拷部分文件）
3. 旧版替换新版时，务必整套覆盖：只换 exe 不换 py 会出现界面打不开

【二、怎么打开】
· 图形界面：双击「启动黑匣子叠加工具.vbs」（不会弹黑窗）
· 命令行：  python bboverlay.py 日志.BBL 视频.MOV --vstart 174 --dur 30

如果双击启动器弹「还没找到 Python」：
  先双击「新电脑配置程序.vbs」，它会自动装 Python 和依赖，
  跑完把 Python 路径记进 python-path.txt，再双击启动器即可。

【三、四步出片（图形界面）】
1. ①选文件：选 Betaflight 导出的 .bbl；选眼镜卡里的 .MOV / .mp4
2. ②做哪一段：填「起点」（视频播放器里看到的秒数）、「时长」
   「日志段」填 0 = 自动（一个日志里有多段飞行时，会逐段对比自动挑对得上、
   时长又够用的那段；也可以填 1/2/3 强制指定某段）
3. ③画面：勾 卫星小地图 / 3D 姿态 / GPS 坐标遮盖 1、2（黑块）/ 顶部渐变压暗；
   选摇杆手别（美国手 MODE2 / 日本手 MODE1）；某个通道反了就勾「通道反向」；
   选底图（在线卫星图，或自己的航拍正射图）
4. ④输出：选输出目录（点「打开文件夹」可直接进去）→ 点「开始生成」

- 「预览一帧」：出一张叠好视频的 JPG。第一次会切图层（几十秒），
  之后和「元素位置」共用同一批图层，1~2 秒出图
- 「元素位置」：调每个元素（左摇杆/右摇杆/姿态/小地图/黑块 1、2）的位置和大小。
  左边直接拖、滚轮改大小，右边也能填数字；摇杆和黑块都有一键对齐
- 所有设置记在 gui_config.json，下次打开还在

【四、输出】
成片：成片_<视频名>_<起点>s-<终点>s.mp4（已抠绿合成）
绿幕：绿幕overlay_<视频名>_<起点>s-<终点>s.mp4（拿去剪映自己叠）
默认输出到程序目录下的「输出」文件夹。

【一键卸载】
不要这个程序了：双击「一键卸载程序.vbs」（界面里「输出」卡片也有「一键卸载程序」按钮）。
它会先列出要删的东西，让你勾选：
  · 运行时文件（缓存/配置/日志）——默认删
  · 输出文件夹里你生成的成片——默认不删
  · pip 依赖 pillow/numpy/pandas——默认不删（别的 Python 程序可能也在用）
  · 本程序装过的 Python——默认不删
  · 整个程序文件夹——默认删
卸载程序只会删它自己目录里的东西，每个路径都会校验，不会碰别的地方。

【五、文件夹里有什么】
bboverlay.py              命令行主程序（界面就是调它）
bboverlay_gui.py          图形界面
bboverlay_layout_editor.py「元素位置」窗口
bbcompose.py              用图层快速拼预览图
bbrender.py               渲染摇杆/姿态/小地图图层
bbminimap.py              在线卫星底图（可换自己的瓦片服务）
bbphotomap.py             自己的航拍图当底图
bbatt.py                  姿态解算（Mahony）
bbsync.py                 自动测视频与日志的时间差
assets/grad.png           顶部渐变压暗（可选）
tools/                    第三方 exe 放这里（仓库不含）
启动黑匣子叠加工具.vbs    日常双击这个
新电脑配置程序.vbs        换新电脑先双击这个

【六、常见问题】
· 提示「找不到 ffmpeg / 解码器」：按第一节把 exe 放进 tools\
· 提示「时间超出日志范围」：起点/时长超过了该段日志长度，换个起点或段
· 提示「算不出底图米/像素」：用自定义航拍图时 EXIF 没有高度/焦距，
  在「标定参数」里手动填米/像素
· 小地图空白：该位置没网下不到瓦片，或日志里没有有效 GPS（室内飞）
· 手别/通道反向改了之后：重新开一次「元素位置」，图层会按新设置重切

【七、注意】
· 小地图默认取高德瓦片，仅供个人学习/本地预览；批量抓取或商用不符合其条款，
  公开使用建议换天地图或自有正射影像（可用环境变量 BBOVERLAY_TILE_URL）
· 飞行请遵守当地无人机管理规定
· 日志和视频含真实 GPS 坐标，分享前注意是否需要遮盖
